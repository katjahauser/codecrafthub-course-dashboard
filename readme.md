# Course API

## 1. Project Overview and Description

CodeCraftHub is a small Flask REST API for managing software developer courses. 

It is the final project in the IBM Coursera Course "Generative AI: Elevate your Software Development Career" and was implemented to serve as both portfolio project and as familiarization with CoPilot in VSCode. 


## 2. Features

- Create, list, retrieve, replace, partially update, and delete courses.
- Assign integer IDs starting at 1 and keep them consecutive after deletion.
- Validate titles, descriptions, dates, and course statuses.
- Generate a `created_at` timestamp when a course is created.
- Create the course data file automatically when it is missing.

Course objects contain `id`, `title`, `description`, `target_date`, `status`, and `created_at`. Valid statuses are `Not started`, `In progress`, and `Completed`. Dates use `YYYY-MM-DD`; timestamps use `YYYY-MM-DD HH:MM:SS`. Course records are stored in `api/courses/courses.json`.

## 5. API Endpoints

All endpoints use the `/api/courses` base path. Requests with a body use JSON. Course IDs are consecutive integers starting from 1.


### Create a course

Endpoint: `POST /api/courses`

```bash
curl -X POST http://127.0.0.1:5000/api/courses \
	-H 'Content-Type: application/json' \
	-d '{"title":"Python Basics","description":"Learn Python basics including lists, common string operations and solving basic mathematical problems.","target_date":"2027-01-15","status":"Not started"}'
```

Returns `201` and a creation message. The ID and `created_at` timestamp are generated by the API.
Do not include `id` or `created_at` in the request; attempts to set these server-managed fields return `400`.


### List all courses

Endpoint: `GET /api/courses`

```bash
curl http://127.0.0.1:5000/api/courses
```

Returns `200` and an array of course objects.


### Get one course

Endpoint: `GET /api/courses/<id>`

```bash
curl http://127.0.0.1:5000/api/courses/1
```

Returns `200` and the course, or `404` if it does not exist.


### Update a course

Endpoint: `PUT /api/courses/<id>` 

`PUT` requires all editable fields: `title`, `description`, `target_date`, and `status`. The server-managed `id` and `created_at` fields cannot be set manually.

```bash
curl -X PUT http://127.0.0.1:5000/api/courses/1 \
	-H 'Content-Type: application/json' \
	-d '{"title":"Python Basics","description":"Learn Python/API basics.","target_date":"2027-02-15","status":"In progress"}'
```

Returns `200` and an update message naming all supplied field values, or `400` if required fields are missing or server-managed fields were included in the request.


### Partially update a course

Endpoint: `PATCH /api/courses/<id>` 

`PATCH` accepts any subset of editable fields: `title`, `description`, `target_date`, and `status`.
The server-managed `id` and `created_at` fields cannot be set manually.

```bash
curl -X PATCH http://127.0.0.1:5000/api/courses/1 \
	-H 'Content-Type: application/json' \
	-d '{"title":"Python Basics","status":"Completed"}'
```

Returns `200` and an update message including the updated fields, or `400` if sever-managed fields were included in the request.


### Delete a course

Endpoint: `DELETE /api/courses/<id>`

```bash
curl -X DELETE http://127.0.0.1:5000/api/courses/1
```

Returns `200` when deleted and a message indicating the deleted course. The remaining course IDs are renumbered consecutively with the last course replacing the deleted one.


## 6. Error Codes

* `400 Bad Request`: invalid values, missing required fields, attempts to set server-managed fields, or updates with no editable fields.
* `404 Not Found`: the requested course or endpoint does not exist.
* `405 Method Not Allowed`: the endpoint exists but does not support the requested HTTP method.
* `409 Conflict`: a course with the same title and description already exists.
* `500 Internal Server Error`: course data could not be read from or written to storage.
