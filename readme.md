# Course API

## 1. Project Overview and Description

A small Flask REST API for managing courses. Course records are stored in `api/courses/courses.json`.

## 2. Features

- Create, list, retrieve, replace, partially update, and delete courses.
- Assign integer IDs starting at 1 and keep them consecutive after deletion.
- Validate titles, descriptions, dates, and course statuses.
- Generate a `created_at` timestamp when a course is created.
- Create the course data file automatically when it is missing.

Course objects contain `id`, `title`, `description`, `target_date`, `status`, and `created_at`. Valid statuses are `Not started`, `In progress`, and `Completed`. Dates use `YYYY-MM-DD`; timestamps use `YYYY-MM-DD HH:MM:SS`.

## 3. Installation Instructions

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 4. How to Run the Application

```bash
python run.py
```

The development server is available at `http://127.0.0.1:5000`.

## 5. API Endpoints

All endpoints use the `/api/courses` base path. Requests with a body use JSON. Course IDs are integers.

### Create a course

`POST /api/courses`

```bash
curl -X POST http://127.0.0.1:5000/api/courses \
	-H 'Content-Type: application/json' \
	-d '{"title":"Python Basics","description":"Learn Python/API basics.","target_date":"2027-01-15","status":"Not started"}'
```

Returns `201` and a creation message. The ID and `created_at` timestamp are generated by the API.

### List all courses

`GET /api/courses`

```bash
curl http://127.0.0.1:5000/api/courses
```

Returns `200` and an array of course objects.

### Get one course

`GET /api/courses/<id>`

```bash
curl http://127.0.0.1:5000/api/courses/1
```

Returns `200` and the course, or `404` if it does not exist.

### Replace a course

`PUT /api/courses/<id>` requires all four editable fields: `title`, `description`, `target_date`, and `status`. The original `created_at` value is retained.

```bash
curl -X PUT http://127.0.0.1:5000/api/courses/1 \
	-H 'Content-Type: application/json' \
	-d '{"title":"Python Basics","description":"Learn Python/API basics.","target_date":"2027-02-15","status":"In progress"}'
```

### Partially update a course

`PATCH /api/courses/<id>` accepts any subset of editable fields.

```bash
curl -X PATCH http://127.0.0.1:5000/api/courses/1 \
	-H 'Content-Type: application/json' \
	-d '{"status":"Completed"}'
```

### Delete a course

`DELETE /api/courses/<id>`

```bash
curl -X DELETE http://127.0.0.1:5000/api/courses/1
```

Returns `200` when deleted; remaining course IDs are renumbered consecutively.

Invalid input and missing required fields return `400`; missing courses return `404`; course data read/write errors return `500`. Duplicate courses return `409`.
